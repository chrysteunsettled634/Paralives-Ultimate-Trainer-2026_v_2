## 🛠️ Available Features

The trainer includes tools to manage your simulation experience. Each feature targets a specific game mechanic.

### Money Management
You can set your funds to any amount. Toggle the infinite money option to prevent your balance from dropping when you purchase furniture or build houses.

### Character Needs
The Needs panel allows you to lock your character's requirements at maximum levels. This stops hunger, energy loss, and other discomforts. You can toggle this off if you prefer a challenge.

### Aging Controls
The freeze-aging tool stops characters from getting older. This works for individual members or the entire household. Enable this if you want to keep your characters at their current age for as long as you like.

### Item Unlocks
This feature removes restrictions on furniture and decorative objects. You can access locked items regardless of your current skill level or progression stage. 

### Skill Levels
You can slide a bar to increase your character's skills instantly. This helps you complete work requirements or hobby goals without waiting for the natural skill gain process.

## 🛡️ Safety and Performance

This trainer operates as a portable application. It does not install background services or change your registry settings. It stays dormant when you close the application window.

We designed the software to be undetected by standard single-player game hooks. Because this is a memory-editing tool, you should run it during single-player sessions only. It will not function correctly if you try to use it within an unsupported or outdated version of the game.

If you experience game lag, close the trainer and restart it. The software handles memory reading in small intervals to keep the game performance high. It uses very little RAM, meaning it works alongside high-end simulation settings without causing crashes.

## 💡 Troubleshooting

If the trainer fails to connect to the game, try these steps:

1. Close the trainer and the game completely.
2. Open the game as an administrator.
3. Open the trainer as an administrator.
4. Check that your game version matches the version of the trainer.
5. Disable your antivirus temporarily if it prevents the trainer from opening your game process.

Ensure you always use the latest release from the repository. We update the file when the game receives patches to ensure compatibility with new game memory addresses. 

We store all configuration data inside a local text file within the same folder as the trainer. If you want to reset all settings to default, simply delete this specific configuration file and restart the application.
